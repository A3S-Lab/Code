# Plan: Add Missing gRPC RPCs + Server-Side AgenticLoop

## Overview

Add missing Observability RPCs, server-side AgenticLoop RPC, and server-side Delegate RPC to the proto, then update client.ts and session.ts.

## 1. Proto Changes (code_agent.proto)

### New RPCs to add:

```protobuf
// === Observability ===
rpc GetToolMetrics(GetToolMetricsRequest) returns (GetToolMetricsResponse);
rpc GetCostSummary(GetCostSummaryRequest) returns (GetCostSummaryResponse);

// === Server-Side AgenticLoop ===
rpc AgenticGenerate(AgenticGenerateRequest) returns (AgenticGenerateResponse);
rpc StreamAgenticGenerate(AgenticGenerateRequest) returns (stream AgenticGenerateEvent);

// === Server-Side Delegation ===
rpc Delegate(DelegateRequest) returns (DelegateResponse);
rpc StreamDelegate(DelegateRequest) returns (stream AgenticGenerateEvent);

// === Queue Stats ===
rpc GetQueueStats(GetQueueStatsRequest) returns (GetQueueStatsResponse);

// === Batch Skill Loading ===
rpc LoadSkillsFromDir(LoadSkillsFromDirRequest) returns (LoadSkillsFromDirResponse);
```

### New Messages:

- GetToolMetrics: per-tool stats (call count, avg duration, errors)
- GetCostSummary: token/cost breakdown by model and day
- AgenticGenerate: server-side AgenticLoop (prompt + options → full result)
- StreamAgenticGenerate: streaming version with AgenticGenerateEvent
- AgenticGenerateEvent: discriminated union of all loop events
- Delegate: server-side subagent delegation
- GetQueueStats: per-lane queue statistics
- LoadSkillsFromDir: batch load skills from directory

## 2. Client.ts Changes

- Verify getToolMetrics/getCostSummary match new proto
- Add agenticGenerate(), streamAgenticGenerate()
- Add delegate(), streamDelegate()
- Add getQueueStats()
- Add loadSkillsFromDir()

## 3. Session.ts Changes

- `send()` → delegate to server-side `AgenticGenerate` RPC
- `sendStream()` → delegate to server-side `StreamAgenticGenerate` RPC
- `delegate()` → delegate to server-side `Delegate` RPC
- `delegateStream()` → delegate to server-side `StreamDelegate` RPC
- `getQueueStats()` → new method
- `loadSkills(dir)` → use `LoadSkillsFromDir` RPC

## Execution Order

1. Update proto (add RPCs + messages)
2. Update client.ts (add new methods)
3. Update session.ts (switch to server-side RPCs)
4. Update index.ts exports
