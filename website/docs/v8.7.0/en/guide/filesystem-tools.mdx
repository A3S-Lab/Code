# AgentDir tools (removed)

AgentDir `tools/` (`kind: mcp` / `kind: script`) and `AgentDirScriptTool`
were part of the filesystem-first serve surface and are **removed**.

Register tools through:

- Host direct tools / SDK session registration
- MCP servers on the session
- Built-in Core tools
