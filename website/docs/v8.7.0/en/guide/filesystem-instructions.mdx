# instructions.md (removed)

`instructions.md` was the role file for a filesystem-first AgentDir main
agent. That convention, and the `serve` daemon that loaded it, are
**removed**.

Project instructions now live in [`AGENTS.md`](/guide/agents-md). Worker
roles for `task` live under [`.a3s/agents/`](/guide/filesystem-agents).
Reusable checklists live in [`.a3s/skills/`](/guide/filesystem-skills).
