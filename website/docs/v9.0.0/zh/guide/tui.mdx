# A3S Code TUI

`a3s code` 是 A3S Code 的交互式终端应用。它由
[`a3s` CLI](https://github.com/A3S-Lab/a3s) 发布，驱动 Rust
`a3s-code-core` 运行时，并使用 [`a3s-tui`](https://github.com/A3S-Lab/TUI)
渲染运行时事件流。

需要现成的终端编程智能体时使用 TUI；要把同一运行时嵌入其他宿主、运行器、
IDE 桥接或受控产品界面时使用 A3S Code SDK。

## 界面结构

| 组成部分      | 仓库                                            | 职责                                                                            |
| ------------- | ----------------------------------------------- | ------------------------------------------------------------------------------- |
| A3S Code SDKs | [A3S-Lab/Code](https://github.com/A3S-Lab/Code) | Rust 运行时 crate，以及 Node.js、Python 和 Go SDK。                             |
| `a3s code`    | [A3S-Lab/a3s](https://github.com/A3S-Lab/a3s)   | 驱动 `a3s-code-core` 会话的终端编程智能体应用。                                 |
| A3S Use       | [A3S-Lab/Use](https://github.com/A3S-Lab/Use)   | 独立发布的 Browser、Office、OCR 与签名应用能力，通过 MCP 和 Skill 投影到 Code。 |
| `a3s-tui`     | [A3S-Lab/TUI](https://github.com/A3S-Lab/TUI)   | CLI 使用的终端界面框架，是渲染器与组件库，不是智能体运行时。                    |

## 安装与启动

运行对应平台的安装脚本：

<Tabs>
<Tab label="macOS / Linux">

```bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://raw.githubusercontent.com/A3S-Lab/a3s/main/install.sh | sh
```

</Tab>
<Tab label="Windows">

```powershell
[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12
irm https://raw.githubusercontent.com/A3S-Lab/a3s/main/install.ps1 | iex
```

</Tab>
</Tabs>

脚本会选择当前系统与架构对应的发布包并校验 SHA-256。也可以使用
`brew install a3s-lab/tap/a3s` 或 `cargo install a3s`。

在希望智能体检查的 Workspace 中运行 CLI：

```bash
a3s code                      # interactive TUI
a3s code --worktree [NAME]    # start in an isolated Git worktree
a3s code resume               # resume the newest session
a3s code resume <session-id>  # resume a selected session
a3s self update               # upgrade the CLI (same updater as /update)
```

全局参数适用于所有命令：`-C <PATH>` 以另一个目录作为启动目录，
`--config <PATH>` 指定唯一的 ACL 配置文件，`--offline` 禁用网络访问与首次使用时的下载。

<a id="configuration"></a>

## 配置

配置使用 A3S ACL。CLI 按以下规则解析：

1. 显式的 `--config <PATH>` 或 `A3S_CONFIG_FILE` 会被单独使用。
2. 否则，用户文件 `~/.a3s/config.acl` 与从 Workspace 向上查找到的最近的
   `.a3s/config.acl` 按层合并，Workspace 层最后应用。

Workspace 层可以配置智能体，但不能改变凭据或源码外发的路由；宿主拥有的外发能力只读取可信的显式层与用户层。

首次启动且不存在显式、Workspace 或用户配置时，CLI 会写入初始的
`~/.a3s/config.acl` 并在内置编辑器中打开。之后可用 `/config` 编辑当前生效的文件。不要把真实密钥和私有端点提交到仓库；模型与凭据配置见 [Providers](/guide/providers)。

## 模式

Shift+Tab 循环切换运行模式：Default、Plan、Reviewer、Auto、Yolo。

| 模式     | 行为                                                                      |
| -------- | ------------------------------------------------------------------------- |
| Default  | 风险感知。安全读取静默执行；有副作用的操作需要确认。                      |
| Plan     | 严格只读规划。评审之后才开始实现。`/plan` 与 `/ask` 选择此模式。          |
| Reviewer | 启用异步的声明与记录对照回复校验器，不接管主智能体流。`/reviewer`。       |
| Auto     | 非交互执行。硬策略与 Workspace 拒绝仍然优先。`/auto`。                    |
| Yolo     | 自动放行高风险评审候选。关键拒绝、受保护路径与离开沙箱仍然优先。`/yolo`。 |

`/permissions` 修改下一轮的模式并列出精确授权。项目授权保存在
`.a3s/permissions.acl`。`/sandbox` 与 `a3s code sandbox status` 报告宿主 Bash 沙箱是否就绪。

## 输入与按键

| 输入        | 操作                                                                |
| ----------- | ------------------------------------------------------------------- |
| `! <cmd>`   | 直接运行 shell 命令。                                               |
| `? <query>` | `/research <query>` 的快捷方式。                                    |
| `@<path>`   | 引用 Workspace 文件；图片文件会成为视觉附件。                       |
| `$<skill>`  | 提及 Skill。Alt/Option+Enter 使其保持粘滞，直到 Esc 或 `/unstick`。 |
| Ctrl+V      | 附加图片。                                                          |
| Enter       | 发送。运行中的轮次会把消息追加到 FIFO 队列。                        |
| Ctrl+O      | 立即发送：取消当前轮次并提升此提示。                                |
| Ctrl+J      | 插入换行。终端上报 Shift 时 Shift+Enter 也可用。                    |
| Up / Down   | 调出会话历史；在菜单中移动选择。                                    |
| PgUp / PgDn | 滚动对话记录或帮助面板。                                            |
| Shift+End   | 跳到最新输出。                                                      |
| Ctrl+T      | 展开完整的工具输出与 diff。                                         |
| Ctrl+R      | 模糊搜索当前会话中的提示。                                          |
| Ctrl+G      | 查看最近一轮文件编辑的 DiffView。                                   |
| Ctrl+B      | 查看委派任务、最近输出与安全取消。                                  |
| Esc         | 中断运行中的轮次、关闭面板或清除粘滞 Skill。                        |
| Ctrl+C 两次 | 退出。                                                              |

`/help` 打开完整的分组参考。

## 斜杠命令

输入 `/` 浏览命令，继续输入可按名称与描述搜索。部分命令只能手动输入，不出现在空浏览列表中。

| 命令                                   | 用途                                                                            |
| -------------------------------------- | ------------------------------------------------------------------------------- |
| `/status`                              | 会话、Workspace、模型、权限模式与 token 用量。                                  |
| `/model`                               | 切换已配置模型与账户模型。                                                      |
| `/effort`                              | 调整模型投入，从 `low` 到 `ultracode`。                                         |
| `/permissions`                         | 修改下一轮权限模式或查看精确授权。                                              |
| `/sandbox`                             | 宿主 Bash 沙箱就绪状态。                                                        |
| `/plan`, `/ask`                        | 只读规划模式。                                                                  |
| `/reviewer`                            | 粘滞的声明与记录对照回复校验器。                                                |
| `/auto`, `/yolo`                       | Auto 与 Yolo 模式的别名。                                                       |
| `/review`                              | 评审工作区、某个提交或分支，不修改文件。                                        |
| `/hooks`                               | 查看、信任、禁用、启用或重新加载生命周期 hook。                                 |
| `/compact`                             | 总结并压缩对话上下文。                                                          |
| `/clear`                               | 重置对话。                                                                      |
| `/rewind`                              | 当文件仍匹配时撤销最近完成的一轮。                                              |
| `/fork`                                | 分支会话；`/fork worktree` 额外创建隔离的 Git worktree。                        |
| `/worktree`                            | 托管 worktree 的状态、交接与清理。                                              |
| `/isolate`                             | 提升、丢弃或记录对话隔离 worktree 的结论。                                      |
| `/relay`                               | 恢复或固定已有会话或后台工作。                                                  |
| `/tasks`, `/queue`, `/history`         | 委派任务、排队提示与提示历史。                                                  |
| `/research`                            | 深度研究；`status`、`explain`、`replay`、`diff` 用于诊断。                      |
| `/ctx`                                 | 上下文中心：搜索历史会话、附加或保存命中项、打开 memory、KB、sleep、evolution。 |
| `/use`                                 | 集成中心：`status`、`repair`、`plugin`、`packages`、`reload`。                  |
| `/init`                                | 为 Workspace 生成 `AGENTS.md`。                                                 |
| `/config`                              | 编辑当前生效的 `config.acl`。                                                   |
| `/checkup`                             | 审计配置，然后评审修复。                                                        |
| `/terminal`                            | 终端能力与 Shift+Enter 修复。                                                   |
| `/copy [transcript]`, `/export [path]` | 复制最新回复或完整记录；将会话导出为 Markdown。                                 |
| `/ide`                                 | 文件浏览器与编辑器。                                                            |
| `/goal`, `/loop`                       | 持久的 Ultracode 目标；工程化循环面板。                                         |
| `/unstick`                             | 清除粘滞 Skill 模式。                                                           |
| `/theme`, `/display`, `/statusline`    | 界面外观。                                                                      |
| `/login`, `/logout`                    | 登录或登出已配置的 OS 账户。                                                    |
| `/update`                              | 升级 `a3s`。                                                                    |
| `/desktop`                             | 在 A3S Desktop 中打开 Workspace。                                               |
| `/help`, `/exit`                       | 完整参考；退出。                                                                |

`/memory`、`/kb`、`/sleep` 与 `/evolution` 仍可使用，推荐使用 `/ctx` 形式。
`/plugin`、`/packages` 与 `/reload` 仍可使用，推荐使用 `/use` 形式。

## 投入档位

`/effort` 为会话选择预算档位：

| 档位        | 思考预算 | 工具轮次 | 续写轮次 | 并行任务 |
| ----------- | -------- | -------- | -------- | -------- |
| `low`       | 2048     | 240      | 4        | 4        |
| `medium`    | 8192     | 800      | 8        | 8        |
| `high`      | 16384    | 1200     | 12       | 8        |
| `xhigh`     | 32768    | 1800     | 16       | 8        |
| `max`       | 65536    | 2400     | 24       | 8        |
| `ultracode` | 65536    | 3200     | 32       | 8        |

交互模式下的并行任务上限为 8，以限制 provider 并发。

## 会话与 Worktree

会话按 Workspace 保存在 `.a3s/tui/sessions`，可恢复的界面状态保存在
`.a3s/tui/session-state`。旧位置 `.a3s/tui-sessions` 中的会话会在启动时迁移。

`a3s code session list|show|export|delete` 管理已保存的会话，不触碰 Workspace 文件。

`a3s code --worktree [NAME]` 与 `/fork worktree` 会在 `~/.a3s/worktrees`
下创建隔离的 Git worktree，分支名为 `a3s/fork-<name>`。未提供名称时自动生成启动标识。

## 命令行子命令

| 命令                             | 用途                                                                                                                             |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `a3s code exec <PROMPT>`         | 运行一次非交互任务。`--mode plan\|default\|auto`、`--force`/`--yolo`、`--tool-policy`、`--web-search`、`--model`、`-i <image>`。 |
| `a3s code resume [ID]`           | 恢复最新或指定的交互会话。                                                                                                       |
| `a3s code research <QUERY>`      | 收集证据并生成 Markdown 与 HTML 报告。`--local-only`、`--web`、`--report-dir`。                                                  |
| `a3s code harness`               | 运行发布清单声明的无界面 Agent 协议服务。                                                                                        |
| `a3s code sandbox status\|setup` | 校验或探测原生本地命令沙箱。                                                                                                     |
| `a3s code hooks`                 | 列出、信任、禁用或启用生命周期 hook。                                                                                            |
| `a3s code schedule`              | 管理工程化循环的持久本地计划。                                                                                                   |
| `a3s code remote diff\|apply`    | 查看或应用远程 Cloud 执行的 Workspace 结果。                                                                                     |
| `a3s code session`               | 列出、查看、导出或删除已保存的会话。                                                                                             |
| `a3s code kb`                    | 管理 Workspace 知识库。                                                                                                          |
| `a3s code context` (`ctx`)       | 搜索或查看持久上下文历史。                                                                                                       |
| `a3s code memory` (`mem`)        | 查看长期记忆。                                                                                                                   |

`a3s code research` 也接受别名 `deepresearch` 与 `deep-research`。

## 深度研究

`/research <query>`、`? <query>` 与 `a3s code research <query>` 启动同一个深度研究运行时。每次运行都会在
`.a3s/research/runs/<run-id>/journal-v2.jsonl` 记录日志；发布的报告写为
`report.md` 与 `index.html`。`/research status|explain|replay|diff` 读取该日志用于诊断。

## A3S Use

Browser、Office 与 OCR 能力来自 A3S Use，并通过专用的 Use worker 运行，该 worker 只能调用
`mcp__use_*` 与 `use_tool_*` 工具。`/use` 显示实时的注册表、MCP 连接、Skill 与 provider；
`/use repair` 只打印显式的修复命令，不做任何修改。

```bash
a3s install use --source release
a3s install use/browser
a3s install use/office
a3s install use/ocr
a3s use ocr doctor --json
```

## 无界面冒烟测试

设置 `A3S_CODE_TUI_SMOKE=1` 可在没有终端界面的情况下，通过 TUI 使用的同一会话流运行一个提示。
`A3S_CODE_TUI_PROMPT` 设置提示；以 `?` 开头运行深度研究，以 `!` 开头运行 shell 命令。
无界面进程没有人类授权，因此意外的确认请求会被拒绝。
