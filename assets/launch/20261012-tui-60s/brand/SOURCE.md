# Official Desktop artwork

`a3s-desktop-icon.png` is an unchanged copy of `apps/work/icons/app/icon.png`.
The Desktop app bundle uses this PNG alongside its ICNS/ICO variants.
`a3s-desktop-mark.png` is an unchanged supplementary copy of
`apps/work/public/a3s-os-logo-mark.png`; the film uses the higher-resolution app icon.
No generated, traced, or redesigned brand mark is used.
