# A3S Code · 光标贯穿

用户选择：方案 1。15 秒，16:9，1920×1080，30 fps，中文，原创音乐和音效。

三个提案分别是光标连续变形、穿入代码的空间运镜、点亮可追溯回路。
选择的是第一种：蓝色光标成为输入、窗口边界、代码定位线、测试结果下划线，
最后折成产品标志。石墨黑、品牌蓝、少量验证绿；Geist / Geist Mono / Noto Sans SC。
不用功能卡片轮播、无关粒子或黑场切页。

参考 `onetake/cases/one-dot-15s/one-dot.mp4`，只取节奏指标，不复用故事或配乐。
实际测量：静止 39.4%，低运动 72.2%，最长静止段 2.75 秒，光流 t80 中位数 0.72。
光流的 smear=0.95，因此不能把该参考的编码文件认定为运动模糊证明。
本片使用 render.py 的真实 180° 快门采样。单元素概念不要求复制参考片的爆发段。
